# 3dreplix.com

Página web de 3DREPLIX, taller de manufactura aditiva en Cuautitlán Izcalli.

- `index.html`: la página.
- `img/`: logos, fotos de piezas y el pasaporte de ejemplo.
- `catalogo-3dreplix-2026.pdf`: catálogo completo (se descarga desde Canva).
- `CNAME`: dominio propio para GitHub Pages.
